Graphiant is a Network-as-a-Service (NaaS) provider that replaces fragmented SD-WAN, MPLS and cloud-networking stacks with a single cloud-native subscription service built on a stateless core architecture. Founded by former Viptela CTO Khalid Raza, the platform connects branches, data centers, public and neo-cloud environments, remote users, AI agents, applications, customers and business partners, delivering private connectivity, end-to-end and post-quantum encryption, data-sovereignty routing controls, Zero Trust Network Access, data loss prevention, deep packet inspection and real-time observability. Everything the Graphiant Portal can do is exposed through a token-authenticated REST/JSON API at api.graphiant.com covering device and edge configuration, sites, circuits and interfaces, LAN segments, BGP and routing policy, gateways, B2B extranet and Data Exchange, assurance and AI-adoption analytics, alarms, notifications and third-party integrations, users, tenants and MSP account switching. Graphiant publishes the OpenAPI bundle that generates its open-source Python and Go SDKs, ships a graphiant CLI, and maintains an Ansible collection of NaaS playbooks.

**Areas:** Networking · Network as a Service · NaaS · Connectivity · SD-WAN · Cloud Networking · Zero Trust · Network Security · Data Sovereignty · Observability · Infrastructure · Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Graphiant: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
